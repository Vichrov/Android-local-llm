# Local Eyes v0.6-Fix

Исправление критической регрессии загрузки GGUF после v0.6.

## Исправлено

- Исправлена ситуация, когда после `Stop`, ухода приложения в фон или другой отмены следующая загрузка LLM завершалась сообщением «Не удалось загрузить GGUF. Проверьте модель и свободную память».
- Причина: v0.6 переносил `NativeLlm.prepare()` после `llm.load()`, а загрузчик llama.cpp использует тот же флаг отмены в progress callback. Поэтому сохранённый `stopped=true` мог отменять загрузку корректного GGUF ещё до генерации.
- Теперь одна операция `load -> generate` получает `prepare()` только в начале serial worker и только если её ticket всё ещё актуален. После этого `cancel()` остаётся активным до завершения всей операции и не может быть случайно сброшен между загрузкой и генерацией.
- Добавлен unit regression test для stale/cancelled operation ticket.

## Сохранено из v0.6

Voice 2.0, безопасный barge-in с AEC fallback, KV-prefix reuse, TTFT/tokens/s метрики, Vosk/GigaAM и полностью локальная работа остаются без отката.

Android 12+ / ARM64. Snapdragon 855+ остаётся минимальной целевой платформой.
