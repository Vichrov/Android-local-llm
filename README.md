# Local Eyes — Android local AI assistant

## v0.4 — GigaAM как второй движок речи

В **Модели и голос → Распознавание речи** доступны Vosk и **GigaAM v3 CTC INT8**. Скачайте модель и нажмите «Выбрать»: выбор действует в ручном вводе, авто-голосе и режиме глаз. GigaAM автоматически скачивает Silero VAD и распознаёт фразы после паузы; Vosk остаётся вариантом по умолчанию с промежуточным текстом.

GigaAM: загрузка 163.3 МБ + 0.64 МБ VAD, распаковка около 225 МБ. Все веса проверяются SHA-256 и скачиваются после установки. Два CPU-потока ASR, один VAD; пауза 0.65 с, сегмент до 15 с. Скорость на Snapdragon 855 не измерена; больший расход RAM по сравнению с Vosk. GigaAM не требует облака или ключа API.

Для сборки дополнительно выполните `python3 scripts/fetch-sherpa.py`: загружается официальный AAR 2.0.1 с проверкой SHA-256. Проверки на Android включают настоящее распознавание русской записи (обычная/тихая), тишину, сброс и выбор движка в UI. `scripts/android_giga_smoke.py` предназначен только для одноразового AOSP userdebug-эмулятора, поскольку подготавливает тестовые файлы через adb root.

## v0.2-Fix: исправление автоматического голоса

В чате появился переключатель **Авто-голос**: ниже него видны уровень микрофона и промежуточный текст Vosk. Сделайте паузу после вопроса — готовая фраза отправится ИИ автоматически. Включение требует скачанных LLM/Vosk RU и разрешения микрофона. Для текстовых ответов в чате голос TTS не обязателен.

Кнопка **Только глаза** включает тот же голосовой тракт на чёрном полноэкранном экране без текста/кнопок. Для этого режима нужен включённый офлайн-голос RU. Выход — удержание экрана или системный «Назад». Системный индикатор микрофона Android не скрывается.

**Причина сбоя v0.2:** самодельный детектор не передавал в Vosk звук с RMS ниже 230, а речь при калибровке могла завысить оценку шума. Готовый результат Vosk дополнительно ожидал окончания фразы по этому же детектору. В Fix фильтр удалён: все PCM-сэмплы во время слушания поступают в Vosk, отправка запускается его собственным endpoint. Начало разговора больше не зависит от порога громкости.

ASR запускается до загрузки LLM. Проверяется фактический запуск записи; при проблеме с источником VOICE_RECOGNITION пробуется MIC. Нулевой сигнал получает явное сообщение. Зафиксирован результат между аудиопотоком и UI, чтобы опрос состояния не включал микрофон до обработки фразы. Старые callbacks после паузы отбрасываются.

Во время генерации и очереди TTS запись приостановлена. После последнего озвученного фрагмента выдерживается 700 мс; затем слушание возобновляется. Перебивание голосом не поддерживается. «Стоп», ручной микрофон, настройки, сворачивание и блокировка выключают авто-режим. Он не включается сам при следующем запуске приложения. После ошибки TTS очередь очищается, чтобы не блокировать возврат к слушанию.

Без слова активации приложение может реагировать на окружающие разговоры и ТВ. Непрерывное декодирование Vosk требует больше CPU, чем старый фильтр, но не отсекает тихую речь. Максимальный непрерывный интервал декодирования — 30 секунд. Аудио не сохраняется и не передаётся на сервер.

Проверки: unit-тесты слабого PCM, немедленного начала, endpoint на фоне шума, пустого результата, лимита и гонок callbacks. `python3 scripts/run_asr_smoke.py` дополнительно проверяет реальную русскую запись обычной громкости, ту же запись с пиковой амплитудой 180 (старый порог никогда бы не открылся) и чистую тишину. Это host-тест на Linux Vosk 0.3.45 с RU 0.22, а не проверка Android AudioRecord; приложение использует Android Vosk 0.3.75. Запись и все зависимости теста закреплены SHA-256. Отчёт включён в артефакты CI. Физический телефон пользователя недоступен; маршрутизацию микрофона и работу конкретной прошивки ещё нужно проверить на устройстве.

Сохранены анимации v0.2 и каталог **Qwen3.5 0.8B FP16** (1.52 ГБ, ориентир RAM 6 ГБ+) / **0.8B Q4_K_M** (533 МБ, ориентир 4 ГБ+). FP16 не гарантирует минимальную задержку на CPU. Источники: [FP16](https://huggingface.co/rdrgzlng/Qwen3.5-0.8B-GGUF), [Q4](https://huggingface.co/unsloth/Qwen3.5-0.8B-GGUF); Apache 2.0, закреплённые ревизии и SHA-256 в каталоге.

## Установка

1. Откройте [Releases](https://github.com/Vichrov/Android-local-llm/releases) и установите APK.
2. В первоначальной настройке скачайте Qwen3.5 2B Q4, Qwen3.5 2B Q8 или Qwen3.5 4B Q6. Нажмите **Выбрать**.
3. Для голосового ввода скачайте **Русская речь · Vosk**. Для текста эта модель не нужна.
4. Установите офлайн-голос русского языка в системных настройках синтеза речи Android. Приложение не выбирает сетевые голоса.
5. Нажмите **К ассистенту**, затем **Говорить** или введите текст. После паузы в речи вопрос отправляется модели. **Стоп** прерывает запись, генерацию и озвучивание.

По умолчанию модели скачиваются через Wi-Fi. Мобильную передачу данных можно включить перед загрузкой. Android DownloadManager сохраняет загрузки при закрытии приложения; после повторного запуска выполняются проверка SHA-256 и установка. Системные ограничения сети могут приостановить загрузку. В настройках можно скачать, выбрать, удалить модель или отменить загрузку. Во время проверки контрольной суммы удаление блокируется.

## Что реализовано

- **LLM:** настоящий JNI-мост к llama.cpp; GGUF; ARMv8-A CPU, до 4 потоков, mmap. Контекст 2048 токенов, ответ до 512 токенов. Короткая история последних двух обменов в RAM. Режим Qwen без вывода рассуждений.
- **ASR:** Vosk small RU 0.22, микрофон 16 kHz, локальное потоковое распознавание, максимум 30 секунд записи. Результат отправляется после распознанной фразы. Разрешение микрофона запрашивается только при первом использовании.
- **TTS:** системный TextToSpeech, только локальный русский голос. Текст поступает в очередь по предложениям или группам полных слов; таймер выпускает небольшие фрагменты во время генерации. Не требуется ждать завершения ответа. Качество и задержка зависят от установленного движка Android.
- **Глаза:** два цветных скруглённых прямоугольника без зрачков и бровей. Моргание, дыхание, состояния ожидания/слушания/обдумывания/озвучивания; простая реакция на тон текста по словам и пунктуации. Это эвристика, а не отдельная модель эмоций.
- **Загрузки:** закреплённые ревизии Hugging Face, SHA-256, свободное место перед загрузкой, установка только после проверки, защита от Zip Slip и переполнения при распаковке ASR.
- **Приватность:** нет телеметрии, облачного ASR/LLM, хранения записей и истории на диске. Интернет требуется только для загрузки весов/голосов. Фоновое прослушивание отсутствует; при уходе с экрана текущая работа останавливается. Android TTS — отдельное приложение выбранного пользователем поставщика.

## Модели

| Модель | Загрузка | Ориентир общей RAM |
|---|---:|---:|
| Qwen3.5 2B Q4_K_M | 1.28 ГБ | 6 ГБ+ |
| Qwen3.5 2B Q8_0 | 2.01 ГБ | 8 ГБ+ |
| Qwen3.5 4B Q6_K | 3.53 ГБ | 12 ГБ+ |
| Vosk small RU 0.22 | 46.2 МБ | Дополнительная память для ASR |

Ориентиры RAM не являются замерами и не гарантируют запуск. Система, другие приложения, буферы llama.cpp и ASR тоже занимают память. На Snapdragon 855 рекомендуем начинать с 2B Q4; Q8 и особенно 4B Q6 могут работать медленно и нагревать телефон. Приложение проверяет доступную RAM перед загрузкой LLM и показывает время до первого текста.

GPU/Adreno, GigaAM и Gemma 4 в v0.2 **не интегрированы**. GPU требует отдельной проверки поддержки операций Qwen3.5 и драйверов на Adreno 640; принудительное включение не гарантирует ускорения. Для первой версии выбраны Qwen и Vosk из разрешённых альтернатив. Мультимодальные входы и управление приложениями телефона не реализованы.

## Сборка

Нужны JDK 17, Android SDK 35, NDK 28.0.13004108, CMake 3.22.1. Gradle 8.11.1 загружается wrapper-скриптом.

```bash
bash scripts/fetch-llama.sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Путь APK: `app/build/outputs/apk/debug/app-debug.apk`. `local.properties` при необходимости содержит `sdk.dir=/path/to/android-sdk` (не коммитить). В Android Studio сначала выполните fetch-скрипт, затем откройте корень проекта.

GitHub Actions делает такую же сборку, сохраняет APK, SHA256SUMS и отчёты тестов/lint. Тег `v0.2-Fix` публикует prerelease. APK подписан **отладочным ключом CI**: это тестовая поставка, не production signing. Следующая сборка может иметь другой ключ; тогда потребуется удаление приложения с потерей скачанных моделей. Для долгосрочных обновлений нужен постоянный приватный release-keystore в GitHub Secrets; приватные ключи не должны попадать в git.

## Проверка на физическом устройстве (пока не выполнена)

- Android 12 / Snapdragon 855 / 6–8 ГБ: установка APK, запуск Q4, время первого токена, токены/с, температура после 10 минут.
- Скачивание по Wi-Fi, разрыв сети, перезапуск приложения, нехватка места, ошибка SHA, отмена и удаление.
- Работа в авиарежиме после загрузок: русский ASR → ответ → TTS.
- Отказ в разрешении микрофона, отсутствие RU TTS, возврат после установки голоса.
- Раннее начало TTS, кириллица/эмодзи на границах токенов, Стоп во время загрузки LLM, записи и генерации.
- Переключение моделей и удаление активной модели, большой запрос и лимит контекста.
- Android с 16-КБ страницами памяти: Vosk 0.3.75 и JNA 5.17.0 имеют ELF-сегменты с выравниванием 16 КБ, llama.cpp собирается NDK 28. Установка и работа на физических устройствах с 16-КБ страницами ещё не проверены; универсальная совместимость со всеми Android 12+ не подтверждена.
