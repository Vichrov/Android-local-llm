# Local Eyes v0.5 · Performance · Living Eyes · Flyme

Крупное локальное обновление для Android 12+ и ARM64, рассчитанное на Snapdragon 855 и новее. Интернет по-прежнему нужен только для скачивания моделей; генерация, распознавание и состояние диалога остаются на устройстве.

## Максимальная производительность

- В ARM64-сборке включены **KleidiAI CPU kernels** с runtime-dispatch и совместимым ARMv8 baseline.
- Prefill batch увеличен с 128 до 256 токенов.
- JNI больше не отправляет почти каждый токен отдельным вызовом: текст передаётся небольшими UTF-8 чанками, уменьшая нагрузку на Java/UI thread.
- Добавлен thermal-aware профиль CPU: на холодном 8-ядерном устройстве допускается до 6 потоков, при нагреве число потоков автоматически ограничивается.
- GPU/OpenCL не включён в обязательный путь v0.5: Snapdragon 855 остаётся на надёжном CPU fallback. Экспериментальный Adreno backend будет тестироваться отдельно.

## Living Eyes v2

- `EyesView` переведён на `Choreographer` вместо постоянного `postInvalidateDelayed()`.
- Активные состояния работают примерно на 60 FPS, спокойный idle — около 30 FPS, скрытый View не перерисовывается.
- Более естественные micro-saccades, редкое двойное моргание, breathing и отдельные реакции LISTENING / THINKING / SPEAKING / ERROR / LOADING_MODEL / SLEEP.
- Сохранён минималистичный принцип: только две скруглённые цветные формы, без реалистичных глаз, зрачков и тяжёлых графических ресурсов.
- Учитывается системное отключение анимаций.

## Flyme-дизайн

- Обновлена светлая и тёмная палитра: нейтральные поверхности, спокойный синий акцент и отдельные цвета состояний глаз.
- Новая минималистичная иконка Local Eyes: центральный AI-sparkle и две лёгкие орбиты.
- Добавлен monochrome launcher layer для тематических иконок Android 13+.
- Adaptive icon остаётся безопасной для масок лаунчеров.

## Совместимость и проверки

- Android 12+ (`minSdk 31`), целевая сборка ARM64.
- Snapdragon 855+ остаётся минимальной целевой платформой по производительности.
- Vosk и GigaAM сохранены без изменения пользовательского сценария.
- CI выполняет unit-тесты, lint, сборку ARM64 APK и startup/UI regression на Android 12 и Android 15.

APK экспериментально подписан debug-ключом. При конфликте сертификатов предыдущую тестовую сборку может потребоваться удалить; удаление приложения также удаляет скачанные модели.
