# Local Eyes v0.4 · GigaAM

Добавлен второй локальный движок распознавания: **GigaAM v3 CTC INT8** через sherpa-onnx 2.0.1 / ONNX Runtime, с Silero VAD для выделения фраз. Vosk остаётся доступен и выбран по умолчанию.

В «Модели и голос» → «Распознавание речи» скачайте GigaAM и нажмите «Выбрать». Выбор сохраняется и действует для кнопки «Говорить», авто-голоса в чате и режима «Только глаза». Ручной и автоматический ввод используют общий механизм захвата с одним владельцем микрофона.

- GigaAM: архив 163.3 МБ, после распаковки примерно 225 МБ. Silero VAD 0.64 МБ скачивается автоматически. Проверка SHA-256 обязательна для обоих файлов. Загрузка через Android DownloadManager с теми же ограничениями Wi-Fi/мобильной сети. Удаление GigaAM удаляет и его VAD.
- GigaAM выдаёт текст **после паузы**, без пословных промежуточных результатов. Пауза около 0.65 с, сегменты до 15 с; предельная длина ручной сессии 30 с. CPU, до двух потоков ASR и один для VAD.
- GigaAM требует больше памяти, чем Vosk; проверяется доступная RAM перед запуском. Скорость на Snapdragon 855 не измерена и не гарантируется. Vosk — более лёгкая альтернатива.
- Микрофон приостанавливается на время генерации/озвучивания и освобождается при уходе из приложения. Аудио не отправляется в сеть и не сохраняется.
- Сохранены темы и исправление запуска v0.3-Fix. Каталог избегает повторных обновлений одинакового текста.

Проверки CI: unit-тесты распаковки/голосовых состояний, lint, запуск на Android 12/15; настоящая русская запись через Android JNI GigaAM, тихая запись, тишина, сброс незавершённой фразы; выбор GigaAM в интерфейсе и сохранение выбора. Эмуляторы x86_64 проверяют тот же код; APK релиза — ARM64. Живой микрофон и производительность конкретного Snapdragon здесь не проверены.

Источники: [GigaAM](https://github.com/salute-developers/GigaAM), [конверсия и runtime](https://github.com/k2-fsa/sherpa-onnx), [Silero VAD](https://github.com/snakers4/silero-vad). Лицензии включены в приложение; веса не включены в APK.

Android 12+, ARM64. Экспериментальная debug-подпись. При конфликте сертификатов потребуется переустановка; удаление приложения удалит скачанные модели.
