# Local Eyes v0.5-IconFix

Исправление иконки приложения без изменений в работе LLM, ASR или голосового режима.

- Возвращён мягкий голубо-фиолетовый градиент центрального AI-символа.
- Орбитальные линии получили плавные цветовые переходы вместо плоских одноцветных штрихов.
- Светлый фон adaptive icon заменён пастельным градиентом.
- Сохранён Android 13+ monochrome icon и совместимость Android 12+.
- Версия приложения: `0.5-IconFix` (`versionCode 9`).

APK подписан тестовым ключом; при несовпадении сертификата с установленной сборкой Android может потребовать переустановку. Удаление приложения удалит локальные модели.
