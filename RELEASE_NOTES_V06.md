# Local Eyes v0.6 · Voice 2.0

Крупное обновление локального голосового режима для Android 12+ / ARM64 с сохранением CPU-базовой совместимости Snapdragon 855+.

## Voice 2.0

- Авто-голос теперь работает как непрерывная foreground-сессия: после ответа Local Eyes снова переходит к прослушиванию без повторного нажатия кнопки.
- Добавлено **перебивание ассистента голосом**. Во время генерации ответ можно прервать сразу; во время озвучивания barge-in разрешается только когда Android действительно предоставляет системный Acoustic Echo Canceler.
- Для duplex-режима сначала используется `VOICE_COMMUNICATION`, затем безопасный fallback на `VOICE_RECOGNITION` и `MIC`.
- При наличии устройства автоматически подключаются Android `AcousticEchoCanceler` и `NoiseSuppressor`. Если AEC недоступен, приложение не оставляет микрофон открытым во время TTS и не пытается распознавать собственный голос.
- Добавлена короткая визуальная реакция `HEARD` у глаз при принятой реплике/перебивании.
- В настройках появился переключатель **«Перебивать ассистента голосом»**.

## Быстрее диалог и озвучивание

- Интервал потоковой выдачи текста в Android TTS уменьшен с 800 до 350 мс, поэтому озвучивание коротких ответов начинается раньше.
- `llama.cpp` теперь повторно использует совпадающий префикс KV-cache между последовательными репликами вместо полного prefill с нуля, когда история диалога совпадает.
- Контекст UI хранит до четырёх последних обменов вместо двух, оставаясь только в RAM.
- В чате показываются измеренные метрики ответа: **TTFT**, **tokens/s** и число повторно использованных KV-токенов.
- Исправлена гонка `cancel/prepare`: новая реплика больше не может случайно возобновить уже отменённую генерацию.

## Совместимость и приватность

- Android 12+ (`minSdk 31`), ARM64.
- Snapdragon 855+ остаётся минимальной целевой платформой; KleidiAI + thermal-aware CPU fallback сохранены.
- Vosk и GigaAM остаются локальными вариантами ASR.
- GPU/OpenCL не включён в обязательный путь v0.6.
- Нет облачного LLM/ASR, телеметрии и фонового постоянного прослушивания. Микрофон активен только в foreground-голосовой сессии.
- CI проверяет unit-тесты, lint, ARM64 APK, запуск/UI на Android 12 и Android 15 и Android GigaAM regression.

Сборка экспериментально подписана debug-ключом. При конфликте сертификата Android может потребовать удалить предыдущую тестовую сборку; удаление приложения также удалит скачанные локальные модели.
